# Student Marks Analysis 📊
  Hi, This is one of my first projects as I started to learn about Data Science and how I can use Python to analyse data.
  For this project, I used a small set of student marks to practice basic data analysis and learn how to present data visually.

## Features of this projest
•Calculates the average marks of the students.
•Finds the highest and lowest marks.
•Identifies the student with the highest mark.
•Creates a bar chart to compare the students’ marks.

## Tools I Used
•Python – Used to create the programme and analyse the marks.
•Matplotlib – Used to create the bar chart.
•Statistics Module – Used to calculate the average.

## Project Files
•student_analysis.py – Contains the Python code.
•student_marks.png – Shows the chart created by the program.

## Running the Project
First, Install Matplotlib:
  python -m pip install matplotlib
Then Run the Python file:
  python student_analysis.py

## What have I learnt?
Throughout this project, I have practiced using Python to calculate basic statistics. I have also learnt how to create charts using Matplotlib. Overall this has helped me to understand how to display data in a simple and meaningful way.
